Join the group photo 🙋

  1. Open data/travelers.js on GitHub and hit the ✏️ pencil.
  2. Copy any block, then make it yours — name, emoji, camera, and the two-letter code of every country you've set foot in.
  3. Commit. That's it — the page updates as soon as your change lands.

Country codes are the same two letters as internet domains (FR, JP, BR…) — the full list is in the table above, and typos get flagged at the top of the page.

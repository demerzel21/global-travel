Join the group photo 🙋

  1. Scroll to Update your stamps, pick yourself — or ➕ New member… — and tap countries on the map (or search them) to add and remove. Your edits auto-save as a draft on this device.
  2. Hit 💾 Save to GitHub and press Submit new issue on the page that opens — a robot commits it, closes the issue, and the site updates itself. Any GitHub login works; no repo access or setup needed.
  3. Optional: ⚡ connect GitHub once for instant, no-extra-tap saves — or 📋 copy the file and paste it over the original on GitHub if you'd rather not use GitHub at all (send it to someone who does).

Prefer editing by hand? The file is plain JavaScript and country codes are the same two letters as internet domains (FR, JP, BR…) — the full list is in the table above, and typos get flagged at the top of the page.

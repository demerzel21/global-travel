💾 Save already works with just a GitHub login (one extra tap on an issue). Connecting a token makes saves instant. One-time setup, about a minute:

  1. Create a fine-grained GitHub token ↗

  3. Permissions → Contents → Read and write. Generate.

The token stays in this browser only — it never touches the repo.
